Peer-to-Peer Encrypted Chat — No Server

Security: messages are encrypted locally using AES-GCM with a key derived from passcode + room. You must share the passcode & room with peers.
Create room (host)
Host generates an Offer SDP. Give the Offer text to each joiner. When a joiner returns an Answer, paste it below and click Accept Answer to complete that peer connection.
Join room (joiner)
Paste host's Offer below, click Create Answer, then copy the Answer and send it back to the host.
Messages older than 1 hour are automatically removed locally. Peers also prune old messages they receive.
